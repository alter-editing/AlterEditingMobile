Исправление TikTok Upload без tiktokstudio.onelink.me

Что изменено:
- Telegram-авторизация не изменялась. Проверка остается как была.
- Кнопка Upload по-прежнему открывает Microsoft Edge.
- Убрана прямая ссылка TikTok Studio, из-за которой Edge переходил на tiktokstudio.onelink.me и пытался открыть приложение TikTok Studio.
- Теперь открывается старая веб-страница загрузки TikTok:
  https://www.tiktok.com/upload/?lang=en

Важно:
- Если TikTok внутри Edge все равно покажет окно открытия приложения, нужно нажать «Отмена».
- Приложение не может программно включить галочку Edge «Версия для ПК», потому что это внутренняя настройка браузера.
