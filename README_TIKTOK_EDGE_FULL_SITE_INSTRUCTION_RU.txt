Обновление TikTok Upload: инструкция для полной версии сайта

Что изменено:
- Telegram-авторизация не изменялась.
- Upload по-прежнему открывает TikTok через Microsoft Edge.
- Перед открытием Edge теперь показывается понятная инструкция: нажать меню ☰ внизу справа и выбрать «Перейти на полную версию сайта».
- Кнопка переименована так, чтобы не создавать ложного впечатления, что приложение само включает настройку Edge.

Причина:
Android-приложение не может автоматически нажать кнопку полной версии сайта внутри Microsoft Edge. Это внутренняя настройка браузера. Поэтому приложение показывает обязательную инструкцию перед переходом.
