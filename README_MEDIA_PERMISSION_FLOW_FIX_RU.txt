Исправление потока разрешений медиа

Проблема:
После системного окна доступа к фото/видео приложение сразу открывало Android Photo Picker. Из-за этого первый системный запрос перекрывался вторым нижним окном выбора медиа.

Что изменено:
- Если разрешение ещё не выдано, приложение только показывает системный запрос доступа.
- Галерея больше не открывается автоматически поверх системного окна разрешений.
- После выдачи доступа пользователь нажимает Select from gallery ещё раз, и уже тогда открывается выбор видео.
- Ограниченный доступ Android 14 теперь распознаётся как limited и не запускает бесконечный повторный запрос.
- Автоматический запрос доступа после авторизации отключён, чтобы системные окна не появлялись неожиданно.

Все предыдущие оптимизации и исправления сохранены.
