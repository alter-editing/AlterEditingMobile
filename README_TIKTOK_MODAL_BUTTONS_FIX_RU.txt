Фикс модального окна публикации TikTok Studio

Что исправлено:
- при нажатии «Опубликовать» скрипт больше не забирает кнопки из модального окна «Продолжить публикацию?»;
- кнопки подтверждения/отмены должны оставаться внутри самого модального окна;
- на заднем фоне больше не должны появляться дубликаты кнопок «Опубликовать»;
- основная логика позиционирования нижней панели публикации сохранена;
- elst / patch-логика / авторизация / релизы / bat-файлы не изменялись.

Проверка:
1. Запусти build-dev-apk.bat.
2. Скачай APK из GitHub Actions → Artifacts.
3. Установи APK и проверь TikTok Studio.
