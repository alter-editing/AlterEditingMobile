Фикс Telegram-авторизации

Что изменено:
- Кнопка «Авторизация» больше не должна зависать после возврата из Telegram.
- При каждом ручном нажатии создаётся новая Telegram auth-сессия.
- Если пользователь случайно закрыл Telegram или вышел назад, повторно нажать кнопку можно почти сразу.
- Старое ожидание авторизации уменьшено, чтобы не держать интерфейс заблокированным.
- При возврате в приложение сбрасывается визуальная блокировка кнопки.
- Проверка Telegram-подписки не отключалась и не упрощалась.
- TikTok/Brave Upload не изменялся.
