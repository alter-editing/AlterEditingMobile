Фикс анимации кнопки Telegram-авторизации

Что изменено:
- Добавлена отдельная принудительная анимация кнопки при touchstart/pointerdown/click.
- Анимация больше не зависит только от CSS :active.
- Надёжное нажатие через click/touchend/pointerup сохранено.
- Не удаляются классы, которые могут отвечать за визуальную анимацию.
- Проверка Telegram-подписки не изменялась.
- TikTok/Brave Upload не изменялся.
