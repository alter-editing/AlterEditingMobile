Обновление: Brave обязателен для Upload

Что изменено:
- другие браузеры полностью убран из сценария Upload.
- Upload открывает TikTok только через Brave: com.brave.browser.
- Если Brave не установлен, приложение открывает страницу Brave в Google Play.
- Больше нет fallback на другие браузеры, Chrome, системный выбор браузера или TikTok-приложение.
- Telegram-авторизация не изменялась.
