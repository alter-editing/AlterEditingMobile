Фикс TikTok WebView: безопасный вход + стабильная загрузка

Что сделано:
- внешний Google-login отключён, чтобы не было белого зависшего экрана после выбора аккаунта;
- для страницы входа TikTok используется mobile User-Agent и mobile viewport;
- для TikTok Studio Upload используется desktop User-Agent и desktop viewport;
- кнопки публикации и модальные окна TikTok не переносятся и не ломаются;
- оставлен только безопасный фикс цвета внутренней карточки выбора видео;
- patch/elst-логика, авторизация приложения, релизы и батники не изменялись.

Важно:
Google-вход внутри WebView может блокироваться самим Google. Самые стабильные способы входа: телефон, почта/логин или QR.
