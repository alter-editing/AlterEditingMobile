Изменения Telegram-авторизации:

1. При запуске приложения экран загрузки не скрывается, пока не выполнится фоновая проверка сохранённой авторизации.
2. Если пользователь уже был авторизован и проверка подтверждает подписку, экран Telegram-авторизации не показывается.
3. Если сервер временно возвращает pending / expired / timeout / error для старого токена, приложение больше не выкидывает пользователя на повторную авторизацию автоматически.
4. Повторная авторизация через Telegram показывается только если сервер явно сообщает, что пользователь не подписан, заблокирован, banned, denied, not_subscribed, not_member и т.п.
5. Последняя успешная проверка сохраняется в lastAuthVerifiedAt, чтобы не дёргать Telegram/сервер при каждом открытии приложения.
6. Ручный выход из аккаунта полностью очищает сохранённую авторизацию и lastAuthVerifiedAt.
