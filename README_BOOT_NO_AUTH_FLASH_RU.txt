Исправление мигания авторизации при запуске

Что изменено:
1. Экран авторизации теперь скрыт в index.html по умолчанию через hidden.
2. Пока приложение находится в состоянии is-booting, auth overlay принудительно не отображается через CSS.
3. Экран авторизации появляется только после фоновой проверки сохранённой авторизации/подписки.

Результат:
При открытии приложения пользователь сначала видит только экран загрузки. Сообщение авторизации больше не должно появляться на секунду перед фоновой анимацией.
