# Alter Editing Method Mobile

Полный проект мобильной версии под Android на Capacitor.

## Что внутри

- Полная структура проекта
- GitHub Actions для сборки APK
- Интерфейс в стиле Alter Editing Method
- Авторизация Telegram по схеме ПК
- Основной сервер: `http://132.243.30.159:3000`
- Запасной сервер: `http://83.147.241.28:3000`
- PATCH без FFmpeg
- Только elst patch
- Без выбора битрейта и без перекодирования

## Как собрать APK через GitHub

1. Создай новый репозиторий.
2. Загрузи все файлы из архива в корень репозитория.
3. Открой вкладку `Actions`.
4. Выбери `Build Android APK`.
5. Нажми `Run workflow`.
6. После зелёной галочки скачай artifact `AlterEditing-debug-apk`.

Перед установкой новой APK удали старую версию с телефона.
