ОДИН БАТНИК ДЛЯ РЕЛИЗА APK

Файл:
release-mobile.bat

Что делает:
1. Считывает текущую версию из package.json.
2. Просит ввести новую версию, например 1.0.2.
3. Обновляет package.json.
4. Обновляет package-lock.json, если он есть.
5. Делает git add .
6. Делает commit: Release vX.X.X
7. Пушит main.
8. Создаёт git tag vX.X.X.
9. Пушит tag в GitHub.
10. GitHub Actions автоматически собирает APK.
11. Если был создан tag vX.X.X, workflow публикует GitHub Release и прикрепляет APK.

Важно:
- Обычный push без tag создаёт только Artifact в Actions.
- Push tag vX.X.X создаёт Release.
- Для обновлений у пользователей APK должен быть подписан тем же release-ключом.
- Если tag уже существует, батник остановится и попросит выбрать новую версию.

Как пользоваться:
1. Открой папку проекта.
2. Запусти release-mobile.bat.
3. Введи новую версию без буквы v, например 1.0.2.
4. Напиши YES для подтверждения.
5. Дождись завершения.
6. Зайди в GitHub Actions и проверь сборку.
7. После успешной сборки APK будет в Releases.

Пример версии:
1.0.2

НЕ вводить:
v1.0.2

Если введёшь v1.0.2, батник всё равно уберёт v автоматически.
