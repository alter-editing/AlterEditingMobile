Исправление позиции кнопок TikTok Studio

Что изменено:
- Нижняя панель действий TikTok Studio больше не закрепляется в самый низ экрана.
- Панель ищет нижнюю часть формы/проверок и ставится ближе к контенту.
- Если TikTok снова изменит DOM и якорь не найдётся, панель будет поставлена примерно на 72% высоты экрана, а не в самый низ.
- Уменьшен искусственный нижний padding desktop-страницы TikTok Studio.
- Страница входа TikTok и основной функционал приложения не изменялись.

Проверять лучше через dev:
build-dev-apk.bat

После успешной проверки можно merge dev -> main и выпускать release-mobile.bat.
