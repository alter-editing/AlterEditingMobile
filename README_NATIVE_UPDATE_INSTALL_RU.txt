Фикс установки обновления

Что изменено:
- При нажатии "Установить" APK больше не открывается обычной ссылкой в браузере.
- Приложение само скачивает APK во временную папку приложения.
- После скачивания сразу открывается системный установщик Android.
- Если Android попросит разрешение "Установка из неизвестных источников" для этого приложения, его нужно включить один раз.

Важно:
- APK всё равно должен быть подписан тем же release-ключом.
- versionCode новой версии должен быть выше старого.
