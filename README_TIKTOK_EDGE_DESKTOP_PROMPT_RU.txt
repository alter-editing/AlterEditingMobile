TikTok Edge Desktop Prompt fix

Что изменено:
- Telegram-авторизация не изменялась.
- Кнопка Upload больше не открывает Edge сразу.
- Сначала появляется окно с текстом «Включить ПК версию».
- После нажатия кнопки приложение открывает Microsoft Edge на прямой странице TikTok Studio Upload:
  https://www.tiktok.com/tiktokstudio/upload?from=creator_center
- Это не управляет внутренней галочкой Edge «Версия для ПК», потому что Android-приложение не может переключать настройки браузера. Но сценарий стал понятнее для пользователя: он подтверждает переход именно в веб/ПК-страницу.
- Если TikTok/Edge всё равно покажет окно открытия TikTok Studio app, пользователь должен нажать «Отмена» и продолжить в браузере.
