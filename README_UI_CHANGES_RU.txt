Изменения:

1. Полностью убрана кнопка Notifications и её панель.
2. После загрузки видео верхний плюс скрывается. Для замены остаётся нижняя кнопка выбора/замены видео.
3. Из пользовательского интерфейса убрано слово elst и прямые упоминания этой логики.
4. Добавлены более плавные анимации в стиле ПК:
   - появление карточек;
   - hover/press для кнопок;
   - glow для блока выбора;
   - плавное исчезновение плюсика после выбора видео;
   - мягкое появление превью видео.
5. Авторизация из предыдущей версии сохранена.
