Исправление TikTok Studio WebView

Проблема: после выбора/загрузки видео страница TikTok Studio в портретном WebView могла получать мобильный viewport width=device-width. Из-за этого редактор пересчитывал страницу неправильно: появлялась огромная пустая область, а нижние кнопки публикации/действий визуально пропадали.

Что изменено:
- TikTok Studio теперь открывается с настоящим desktop viewport 1280px.
- Убрано принудительное width=device-width для TikTok WebView.
- Включён overview mode и начальный масштаб 70%, чтобы весь desktop-интерфейс не обрезался на телефоне.
- Оставлены zoom/scroll, чтобы пользователь мог приближать и двигать страницу.
- Функционал patch/elst, авторизация, релизы и основные оптимизации не изменены.
