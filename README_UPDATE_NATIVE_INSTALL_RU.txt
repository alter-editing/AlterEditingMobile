Обновление APK теперь не открывается через GitHub/Browser.

При нажатии «Установить» приложение должно:
1. скачать APK во внутренний cache приложения;
2. сразу открыть системный установщик Android;
3. при необходимости попросить разрешение «Установка из неизвестных источников».

Если Android открыл настройки разрешения, включите разрешение для приложения и нажмите «Установить» в обновлении ещё раз.
