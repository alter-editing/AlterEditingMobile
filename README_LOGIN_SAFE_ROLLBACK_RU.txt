Безопасный откат TikTok login

Что изменено:
- Убраны агрессивные JS/CSS правки страницы входа TikTok.
- Вход TikTok больше не должен зависать на вечном значке TikTok.
- Для страницы входа оставлен mobile User-Agent.
- Переходы в App Store / Google Play / tiktok:// по-прежнему блокируются, чтобы приложение не уводило пользователя наружу.
- Страница TikTok Studio upload оставлена в desktop viewport.
- Кнопки публикации и модальные окна не двигаются.
- elst / patch-логика не тронута.

build-dev-apk.bat
