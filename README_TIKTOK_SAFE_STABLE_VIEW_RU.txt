Безопасный вариант TikTok Studio

Что сделано:
- отключены все JS-фиксы, которые переносили/двигали кнопки Опубликовать / Сохранить / Удалить;
- кнопки TikTok Studio больше не трогаются и остаются в родной логике TikTok;
- оставлены только безопасные правки viewport/zoom/scroll;
- оставлен фикс белого фона центрального блока выбора видео;
- логин TikTok остаётся в мобильном viewport;
- TikTok Studio / upload остаётся в desktop viewport 1280px;
- elst, patch-логика, авторизация, релизы и батники не изменены.

Проверка:
build-dev-apk.bat

Потом скачать APK из GitHub Actions -> Artifacts и установить на телефон.
