Изменения в этой версии:

1. Удалены лишние файлы из архива:
- .git
- старые README-файлы от прошлых фиксов
- неиспользуемые PNG-инструкции Edge
- временные build/node_modules/dist файлы не включены в архив

2. Авторизация Telegram:
- сохранённая авторизация больше не сбрасывается при каждом перезапуске приложения;
- приложение повторно просит Telegram-авторизацию только если сервер явно вернул blocked/banned/unsubscribed/not_subscribed/not_member/subscription_required/denied;
- временный pending/expired/network-ответ больше не разлогинивает пользователя автоматически.

3. Ошибка формата MP4/MOV:
- проверка выбора файла стала мягче: кроме расширения учитывается MIME type Android;
- валидные MP4/MOV без elst больше не получают ложную ошибку «формат не поддерживается»;
- если elst найден — применяется старый патч;
- если elst отсутствует — файл сохраняется как валидный MP4/MOV без падения в ошибку.

Проверка: npm run build проходит успешно.
