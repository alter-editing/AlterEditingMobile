Жёсткий фикс кнопки Telegram-авторизации

Что изменено:
- Кнопка «Авторизация» теперь слушает click, touchend и pointerup.
- Принудительно сняты disabled/pointer-events блокировки.
- Добавлен защитный обработчик на auth overlay.
- Если пользователь закрыл Telegram или вернулся назад, кнопку можно нажать повторно почти сразу.
- Каждое ручное нажатие создаёт новую Telegram auth-сессию.
- Проверка Telegram-подписки сохранена.
- TikTok/Brave Upload не изменялся.
