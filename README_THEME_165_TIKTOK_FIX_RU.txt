Исправления в этой версии:

1. Смена темы
- Возвращена лёгкая анимация переключения темы.
- Убраны тяжёлые blur/backdrop-filter эффекты на карточках.
- Убрано отключение box-shadow во время смены темы, из-за которого окно визуально дёргалось.
- Анимация теперь сделана через лёгкий overlay fade и не должна вызывать лаги на слабых устройствах.

2. Ограничение видео 165 МБ
- Видео больше 165 МБ теперь не принимается.
- Проверка стоит при выборе файла и перед нажатием Patch.
- Ошибка показывается снизу через обычный toast с анимацией входа/выхода.
- Переводы добавлены на RU / EN / TR.

3. TikTok Web Upload
- Встроенный WebView использует desktop User-Agent.
- m.tiktok.com / vm.tiktok.com / vt.tiktok.com принудительно переводятся на www.tiktok.com.
- tiktok://, snssdk:// и intent:// блокируются, чтобы не открывалось мобильное приложение TikTok.

Важно:
Google может блокировать вход через встроенный WebView и показывать ошибку "браузер или приложение небезопасны". Это ограничение Google, а не ошибка проекта. Desktop-версия TikTok внутри приложения всё равно форсируется, но Google-login в WebView может не пройти.
