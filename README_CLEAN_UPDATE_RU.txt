Alter Editing Mobile — очищенная сборка

Оставлено:
- build-dev-apk.bat — тестовая сборка в ветку dev
- build-main-apk.bat — сборка в ветку main
- build-apk.bat — совместимость со старым запуском
- release-mobile.bat — официальный релиз в GitHub Releases
- create-release-keystore.bat — создание ключа подписи
- src, scripts, assets, .github/workflows

Изменения:
- логика авторизации TikTok оставлена как в исходном архиве;
- удалены старые временные README-файлы от прошлых фиксов;
- добавлена проверка обновления при запуске приложения и при возвращении приложения на экран;
- если в GitHub Releases есть новая версия с APK, приложение показывает окно обновления.

Важно:
Чтобы обновление ставилось поверх старой версии, APK должны быть подписаны одним и тем же ключом, а versionCode новой версии должен быть выше.
