Что исправлено

1. Панель TikTok Studio
- Панель Опубликовать / Сохранить / Удалить больше не выглядит как отдельное плавающее окно.
- Убраны белая плашка, тень и рамка.
- Панель теперь ставится ближе к левой форме TikTok Studio, а не растягивается на весь экран.

2. APK-сборки и обновление поверх старой версии
- Если в GitHub Secrets есть Android signing keys, обычные build-dev/build-main артефакты теперь тоже собираются как release-signed APK.
- Это помогает ставить APK поверх уже установленной release-версии с тем же package name и тем же ключом.

Важно
- Android не разрешает обновлять приложение, если старая версия подписана другим ключом.
- Если на телефоне сейчас стоит APK, который был собран раньше как debug APK или другим ключом, его придётся удалить один раз и поставить release-signed APK из Releases.
- После этого будущие релизы, подписанные тем же alter-release-key.jks, будут обновляться поверх старой версии нормально.

Проверка
- Для теста запускай build-dev-apk.bat.
- Для релиза пользователям запускай release-mobile.bat и увеличивай версию.
