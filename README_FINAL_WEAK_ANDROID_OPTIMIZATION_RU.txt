Финальная оптимизация под слабые Android-устройства

Что изменено:

1. Сохранён прежний функционал:
- patch MP4/MOV через elst;
- авторизация Telegram;
- вход в TikTok;
- текущий UI и визуальные анимации.

2. Снижена нагрузка на слабые телефоны:
- частицы стали легче и реже перерисовываются на low-end устройствах;
- blur/тени автоматически упрощаются на устройствах с малым объёмом памяти или малым количеством ядер;
- анимации оставлены, но на слабых телефонах они короче и работают только через transform/opacity;
- видео-превью больше не проигрывается в цикле, а показывает кадр без постоянной нагрузки на CPU/GPU.

3. Улучшена стабильность Android WebView:
- состояние авторизации сохраняется до открытия Telegram;
- после возврата из Telegram приложение продолжает проверку авторизации;
- добавлены pause/resume/appStateChange/visibilitychange обработчики;
- при переходе во внешний экран приложение временно ставит декоративные анимации на паузу;
- MainActivity настроен на сохранение состояния при изменениях конфигурации Android;
- добавлены largeHeap и дополнительные параметры сохранения task state.

4. Снижены пики памяти при patch:
- потоковая обработка использует меньшие чанки на слабых телефонах;
- проверка already-patched больше не читает весь файл целиком в память;
- сохранение в галерею остаётся чанковым.

Ограничение Android:
если система полностью убьёт процесс приложения во время выбора файла, JavaScript File-объект физически невозможно восстановить без повторного выбора. Эта версия делает всё, чтобы Android реже убивал WebView и чтобы авторизация восстанавливалась после возврата.
