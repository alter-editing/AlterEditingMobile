Исправление TikTok Studio WebView

Что изменено:
- убран серый/отличающийся фон в центральной части страницы загрузки TikTok Studio;
- основные контейнеры страницы принудительно приводятся к единому белому фону;
- панель кнопок Опубликовать / Сохранить / Удалить остаётся в потоке страницы, без отдельного окна;
- скрываются боковые кнопки/иконки TikTok Studio, которые могут уводить в рекомендации, профиль или другие страницы;
- клики по ссылкам TikTok вне upload/studio перехватываются и возвращают пользователя на страницу загрузки;
- загрузка и вход в TikTok сохраняются.

Не трогалось:
- patch/elst логика;
- авторизация приложения;
- GitHub Releases;
- build-dev/build-main батники.

Проверка:
1. Распаковать архив поверх проекта с заменой файлов.
2. Запустить build-dev-apk.bat.
3. Скачать APK из GitHub Actions -> Artifacts.
4. Установить и проверить страницу загрузки TikTok Studio.
