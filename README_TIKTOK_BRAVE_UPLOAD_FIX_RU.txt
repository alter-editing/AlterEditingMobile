Обновление: Upload через Brave

Что изменено:
- Upload теперь открывает TikTok Upload через браузер Brave.
- Основной Android package для Brave: com.brave.browser.
- Edge оставлен только как возможный запасной вариант, если в коде используется список fallback-браузеров.
- Текст инструкции изменён с Microsoft Edge на Brave.
- Фотографии-инструкции оставлены те же, так как интерфейс меню Brave/Edge в этом сценарии используется одинаково по смыслу.
- Telegram-авторизация не изменялась.
