Обновление: Upload через Brave

Что изменено:
- Upload теперь открывает TikTok Upload через браузер Brave.
- Основной Android package для Brave: com.brave.browser.
- другие браузеры оставлен только как возможный запасной вариант, если в коде используется список fallback-браузеров.
- Текст инструкции изменён с другие браузеры на Brave.
- Фотографии-инструкции оставлены те же, так как интерфейс меню Brave/другие браузеры в этом сценарии используется одинаково по смыслу.
- Telegram-авторизация не изменялась.
