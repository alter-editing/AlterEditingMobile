Исправление TikTok Studio WebView: нижние кнопки публикации

Что изменено:
- TikTok Studio продолжает открываться как desktop-страница.
- Добавлен безопасный CSS/JS-fix для TikTok Studio после загрузки видео.
- Если нижняя панель с кнопками публикации уезжает за пределы экрана, приложение закрепляет её снизу поверх страницы.
- Добавлен нижний padding, чтобы контент не перекрывался панелью.
- Patch/elst, авторизация, автообновления и основной UI не изменены.

Зачем это нужно:
На некоторых Android WebView TikTok Studio после загрузки видео неправильно рассчитывает высоту desktop-страницы. Из-за этого появляется большая белая область, а кнопки публикации визуально пропадают ниже экрана. Этот фикс принудительно возвращает панель действий в видимую область.
