Исправление сброса приложения после выбора файла / Telegram

Что изменено:
- pending auth session теперь сохраняется сразу в Preferences до открытия Telegram;
- после возврата в приложение автоматически продолжается проверка авторизации;
- добавлена обработка appStateChange / resume / pause / visibilitychange / focus;
- приложение не должно сбрасывать экран авторизации при коротком уходе в Telegram;
- Android MainActivity получает singleTask, alwaysRetainTaskState и configChanges, чтобы WebView реже пересоздавался на слабых телефонах и агрессивных прошивках;
- при возврате состояние темы, авторизации и текущего UI аккуратно перечитывается из постоянных настроек.

Важно:
- Сам файл видео нельзя полноценно восстановить после полного убийства WebView системой Android, потому что объект File хранится только в памяти. Но приложение теперь реже пересоздаётся при открытии галереи/Telegram и не теряет auth-сессию.
