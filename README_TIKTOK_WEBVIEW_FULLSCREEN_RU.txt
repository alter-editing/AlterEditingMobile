Исправление TikTok WebView

Что изменено:
1. Окно TikTok WebView открывается на всю доступную область экрана.
2. После входа в TikTok Studio страница больше не сжимается в маленький обзорный масштаб.
3. Оставлен desktop User-Agent, чтобы TikTok открывался как веб/ПК-версия.
4. Ссылки tiktok://, snssdk:// и intent:// по-прежнему блокируются, чтобы приложение TikTok не открывалось поверх WebView.
5. Включён скрытый pinch-zoom: пользователю можно приблизить страницу жестом, но системные кнопки зума не показываются.

Что делать:
1. Распакуйте архив.
2. Залейте содержимое папки 28t в GitHub-репозиторий.
3. Запустите Actions -> Build APK.
4. Установите новый APK.
